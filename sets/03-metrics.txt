@@ smooth-cross-entropy | Cross-Entropy with Label Smoothing | 进阶 | 损失与评估 | N

对二分类 logits 计算平均 focal loss。
p_t 是正确类别的概率。正例权重 alpha、负例权重 1-alpha，损失为 -alpha_t·(1-p_t)^gamma·log(p_t)。
? 用带符号的 logit 和 logaddexp 求 log(p_t)，再用 expm1 精确计算 1-p_t。

@@ roc-auc | ROC AUC with Ties | 挑战 | 损失与评估 | N
roc_auc(scores, labels)
计算二分类 ROC AUC，正确处理正负样本同分。
labels 为 0/1 且两类都存在。AUC 等于随机正例分数大于随机负例的概率，同分计 0.5。目标 O(N log N)。
? 稳定排序后逐个分数组处理，同一分数组内的负例只给半个积分。
---
    order = np.argsort(scores, kind="stable")
    ranked_scores = scores[order]
    ranked_labels = labels[order]
    edges = np.r_[0, np.flatnonzero(ranked_scores[1:] != ranked_scores[:-1]) + 1, len(scores)]
    wins = 0.
    seen_negative = 0
    for begin, end in zip(edges[:-1], edges[1:]):
        positive = int(ranked_labels[begin:end].sum())
        negative = end - begin - positive
        wins += positive * (seen_negative + .5 * negative)
        seen_negative += negative
    return float(wins / (int(labels.sum()) * seen_negative))
---

全部同分 | (a([4.,4.,4.]), a([0,1,1])) => .5
正例分数更低 | (a([0.,1.,2.]), a([1,0,0])) => 0.

@@ average-precision | Average Precision at Score Thresholds | 挑战 | 损失与评估 | N
average_precision(scores, labels)
计算不插值的二分类 average precision。
每个不同分数作为阈值，同分必须整组纳入。AP 是 sum(precision·Δrecall)。无正例时返回 0。
? 降序排序并累计 TP，从每个同分组的最后一项读取 precision 和 recall。
---
    total = labels.sum()
    if total == 0:
        return 0.
    order = np.argsort(-scores, kind="stable")
    ranked_scores = scores[order]
    stops = np.r_[np.flatnonzero(ranked_scores[1:] != ranked_scores[:-1]), len(scores)-1]
    tp = np.cumsum(labels[order])[stops]
    precision = tp / (stops+1)
    return float(np.dot(precision, np.diff(np.r_[0, tp])) / total)
---

全部同分 | (a([7.,7.,7.]), a([0,1,0])) => 1/3
