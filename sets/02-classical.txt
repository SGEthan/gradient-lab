@@ decision-stump | Best Binary Decision Stump | 挑战 | 经典机器学习 | N
best_stump(values, labels)
在单个连续特征上拟合使用 Gini impurity 的二分类决策树桩。
只在相邻不同值的中点切分。返回 (threshold, weighted_gini)，同分选最小阈值。若无切分，返回 (None, 原 Gini)。
? 排序后前缀累计正样本数，一次向量化算出全部候选切分的两侧不纯度。
---
    order = np.argsort(values, kind="stable")
    ordered = values[order]
    positive = np.cumsum(labels[order])
    n = len(values)
    cut = np.flatnonzero(ordered[1:] != ordered[:-1]) + 1
    if not len(cut):
        rate = positive[-1] / n
        return None, float(2. * rate * (1. - rate))
    left_rate = positive[cut - 1] / cut
    right_rate = (positive[-1] - positive[cut - 1]) / (n - cut)
    loss = (cut * left_rate * (1-left_rate) + (n-cut) * right_rate * (1-right_rate)) * (2/n)
    best = cut[np.flatnonzero(np.isclose(loss, loss.min(), rtol=0., atol=1e-12))[0]]
    return float((ordered[best - 1] + ordered[best]) / 2), float(loss[cut == best][0])
