masked_attention(q, k, v, mask=None)
实现带布尔 mask 的 scaled dot-product attention。query 和 key 可以有不同长度。
q 为 [B,H,Tq,D]，k 为 [B,H,Tk,D]，v 为 [B,H,Tk,Dv]。mask 可广播到 [B,H,Tq,Tk]，True 表示可见。
沿 key 轴归一化。一个 query 全被遮挡时输出为零。返回 [B,H,Tq,Dv]。
? 为全遮挡行准备有限的归一化中间值，再把这些权重置零。
---
    score = q @ k.swapaxes(-1,-2) / np.sqrt(q.shape[-1])
    if mask is None:
        mask = True
    score = np.where(mask, score, -np.inf)
    visible = np.any(np.broadcast_to(mask, score.shape), axis=-1, keepdims=True)
    safe_score = np.where(visible, score, 0.)
    weight = np.exp(safe_score - safe_score.max(axis=-1, keepdims=True))
    return np.where(visible, weight / weight.sum(axis=-1, keepdims=True), 0.) @ v

@@ clip-loss | Symmetric CLIP Loss | 进阶 | 损失与评估 | N
clip_loss(images, texts, temperature)
给定成对图文向量，用 batch 内其他样本做负例并计算双向对比损失。
两组输入均为 [B,D]。逐行 L2 归一化，范数最低取 1e-12。相似度除以正数 temperature。返回两个方向交叉熵的平均值。
? 使用同一个相似度矩阵的行和列，正例始终位于对角线。
---
    u = images / np.maximum(np.linalg.norm(images,axis=1,keepdims=True),1e-12)
    v = texts / np.maximum(np.linalg.norm(texts,axis=1,keepdims=True),1e-12)
    scores = (u @ v.T) / temperature
    forward = np.logaddexp.reduce(scores,axis=1) - scores.diagonal()
    reverse = np.logaddexp.reduce(scores,axis=0) - scores.diagonal()
    return float((forward+reverse).mean()/2)

@@ gate-calibration | Calibrate a Write Gate | 挑战 | 数据与流式系统 | N
calibrate_gate(logits, target)
用共享标量 bias 把一组 sigmoid 写入率的均值调到指定目标。
logits 为非空一维 float64，取值在 [-1000,1000]。target 在 [1e-5,1-1e-5]。返回 Python float b，使 mean(sigmoid(logits+b)) 与目标相差不超过 1e-7。
? 用 target 的 logit 减掉输入最大/最小值，得到二分区间。
---
    center = np.log(target) - np.log1p(-target)
    lo = center - logits.max()
    hi = center - logits.min()
    for _ in range(48):
        mid = (lo+hi)/2
        mean = np.exp(-np.logaddexp(0.,-(logits+mid))).mean()
        if mean < target:
            lo = mid
        else:
            hi = mid
    return float((lo+hi)/2)
